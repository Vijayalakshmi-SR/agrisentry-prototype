# AgriSentry Interactive Prototype

Static SIH demo built from the supplied AgriSentry/Figma screen exports.

## Main farmer demo flow
Welcome → Farmer Dashboard → Crop Scan → Analysis Result → Combined Risk → Crop Risk Map → Send SMS Alert → SMS Sent

Additional screens:
- Early Risk Prediction
- Alert Details
- Agriculture Officer Field Risk Assessment

## GitHub Pages
1. Create a public GitHub repository, for example `agrisentry-prototype`.
2. Upload `index.html` and the entire `assets` folder.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Open the generated public Pages URL in an incognito window to verify that no login is required.

## Notes
This is a static clickable prototype. The supplied screenshots are presented as screens and the navigation hotspots reproduce a demo flow; it does not claim that SMS, AI inference, satellite processing, or backend services are actually executing.
